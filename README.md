# Editor de Desenhos (Tkinter) — Projeto de Programação A 2026-1

Aplicativo de desenho ao estilo Google Drawings / LibreOffice Draw, desenvolvido em
Python + Tkinter para a disciplina de Programação A (UFS, 2026-1).

## Requisitos

- Python **3.10** ou superior
- Tkinter (vem com o Python na maioria dos sistemas; no Linux pode exigir o pacote
  `python3-tk`. Teste com `python -m tkinter`)

## Como executar

```bash
python main.py
```

## Funcionalidades atuais (Entrega 1 — tag `imperativa.1`)

- Desenhar **linha**
- Desenhar **mão livre** (rabisco)
- Desenhar **retângulo**
- Desenhar **oval**
- Escolher **cor de borda**
- Escolher **cor de preenchimento**

> Implementação ainda imperativa (com `if`/`elif` por tipo de ferramenta).
> A refatoração para Orientação a Objetos começa na Entrega 2 (`OO.1`).
